📊 SQL Data Exploration Project
This project showcases my SQL skills in data exploration, cleaning, and querying. It is part of my portfolio as a data analyst and demonstrates how I approach extracting insights from structured data using SQL.

🔍 Project Overview
Tools Used: SQL (MySQL)

Focus Areas:

Data cleaning using WHERE, DISTINCT, and IS NOT NULL clauses

Aggregation and grouping with GROUP BY, HAVING, and functions like SUM(), AVG(), COUNT()

Table joins and data relationships (INNER JOIN)

Filtering and sorting data efficiently

Using subqueries and derived tables

📁 File Details
sql_query_p1.sql: Contains all the SQL queries used in this project. It demonstrates progressive steps taken to explore, clean, and summarize the data.

🎯 Objective
The objective of this project is to simulate real-world data analysis tasks by:

Answering business-relevant questions with SQL queries

Practicing analytical thinking through dataset exploration

Demonstrating proficiency in writing clean and optimized SQL
